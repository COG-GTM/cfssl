THE REVOKE ENDPOINT

Endpoint: /api/v1/cfssl/revoke
Method:   POST

Required parameters:

    * token: the authentication token
    * request: an encoded JSON revocation request containing:

        * serial: a string specifying the serial number of a certificate in decimal format
        * authority_key_id: a string specifying the authority key identifier
          of the certificate to be revoked; this is used to distinguish
          which private key was used to sign the certificate. Should be formatted without colons and all lowercase.
        * reason: a string identifying why the certificate was revoked; see,
          for example, ReasonStringToCode in the ocsp package or section
          4.2.1.13 of RFC 5280. The "reasons" used here are the ReasonFlag
          names in said RFC.

The request and token use the same authenticated request format as the
authenticated signing endpoint. The server must be configured with an
authentication key named "revoke" in the `auth_keys` section, or with a
default signing profile that specifies an `auth_key`. The endpoint is not
enabled without an authentication provider.

Optional parameters:

    The following parameters might be used by the authenticator as part of
    the authentication process:

    * timestamp: a Unix timestamp
    * remote_address: an address used in making the request.

Result:

    The returned result is an empty JSON object

Example:

    $ curl -d '{"token": "<authentication token>",       \
            "request": "<base64-encoded JSON revocation request>"}' \
          ${CFSSL_HOST}/api/v1/cfssl/revoke
